SPORTS LIVE TV — Android অ্যাপ প্রজেক্ট

এই প্রজেক্টটি আপনার প্রকাশিত ওয়েবসাইটকে Android WebView অ্যাপের ভিতরে দেখায়।
এটি APK ফাইল নয়; APK বানাতে Android Studio-তে Build করতে হবে।

ওয়েবসাইট:
https://sportslivetv.barcelo2026-kk.workers.dev/

ফিচার:
- অ্যাপ চালু হলে ওয়েবসাইট খুলবে
- JavaScript ও DOM storage চালু
- Back বাটনে আগের পেজে যাবে
- লোডিং প্রগ্রেস
- ওয়েবসাইটের বাইরে HTTPS লিংক বাইরের ব্রাউজারে খুলবে
- ভিডিও fullscreen সমর্থনের জন্য WebChromeClient

বিল্ড:
1. Android Studio-তে প্রজেক্ট ফোল্ডারটি খুলুন।
2. Gradle sync সম্পূর্ণ হতে দিন।
3. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
4. Build সফল হলে APK-এর অবস্থান Android Studio দেখাবে।

নোট:
- APK তৈরি/ইনস্টল করার পর নিজের ডিভাইসে পরীক্ষা করুন।
- লাইভ স্ট্রিমের কাজ করা নির্ভর করে ওয়েবসাইট, সম্প্রচারকের অনুমতি, নেটওয়ার্ক ও WebView সমর্থনের ওপর।
- শুধু যেসব স্ট্রিম ব্যবহারের অনুমতি আছে সেগুলো ব্যবহার করুন।
